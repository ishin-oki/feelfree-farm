# FeelFree FARM

野菜をつくる人と、食べる人を、もっと近くに。

季節の収穫情報と作り手の想いを伝える、FeelFree FARMのメインサイトです。スマートフォンを中心に設計し、写真・イラスト・FFF専用ロゴを同梱しています。

## 公開サイト

[FeelFree FARMを見る](https://ishin-oki.github.io/feelfree-farm/)

## ダウンロード

[サイト一式をダウンロード（ZIP）](https://github.com/ishin-oki/feelfree-farm/raw/refs/heads/main/feelfree-farm.zip)

ZIPを展開し、feelfree-farmフォルダのindex.htmlを開くと閲覧できます。画像を含むフォルダ構成はそのまま保ってください。Webサーバーへの設置にも対応しています。

## 現在の状態

2026年10月4日改訂版。正式公開版です。販売受付は準備中です。販売条件と確認用フォームは収穫欄で展開できます。袋数・受取方法・合計金額・予約内容の確認が動作します。実際の注文送信、在庫確保、決済は行いません。価格・数量・受取情報は仮設定で、Instagramは団体公式 @feel.free.npo2023 へ接続済みです。

## 更新箇所

- index.html：収穫情報、商品説明、販売条件、問い合わせ先。
- config.js：計算用価格、最大袋数、公式Instagram URL。価格を変える場合はページ内の表示も合わせて更新してください。
- assets：写真、イラスト、FFF専用ロゴ、運営団体ロゴ。

実際の販売開始前に、受付先・販売条件・運営者情報を設定してください。

## 画像・ロゴについて

FeelFree提供写真と団体ロゴ、生成イラスト、生成したFFF専用ロゴを使用しています。掲載素材の再利用については運営団体への確認が必要です。オープンソースライセンスによる利用許諾は付与していません。

## 改訂内容

ページを7セクションに整理。取材記事の本人の言葉と出典を追加し、団体公式Instagram・問い合わせ窓口に接続。主要導線を販売受付前の状態に合わせ、販売条件・記事・将来構想は折りたたみに整理。季節のかごはコンパクトに、手渡しアニメーションを主な見せ場として維持しました。
